2. Como iniciar

  1. Extraia o ZIP inteiro. Preserve a organização das pastas.
  2. Execute PREPARAR_DEPENDENCIAS.cmd. Ele verifica Node.js 24 e cloudflared, baixa as ferramentas que faltarem e instala as dependências. Use Windows de 64 bits e mantenha a internet conectada. As ferramentas locais ficam em codigo/.runtime/ferramentas; instalações compatíveis existentes são aproveitadas.
  3. Execute INICIAR_APRESENTACAO.cmd na pasta deste arquivo. Ele abre a API e cria o túnel HTTPS.
  4. Aguarde CONEXÃO VERIFICADA. Copie a URL HTTPS exibida; /health ao final permite conferir a resposta no navegador.
  5. No login do app, toque em Configurar conexão, informe 180504 e toque em Liberar configuração. Cole a URL base sem /health, toque em Testar e salvar conexão e depois Voltar para entrar. Entre com Roger ou cadastre a conta do professor.
  6. Mantenha janela, computador e internet ativos. Faça um ensaio do mapa, dados e sincronização antes de apresentar.

Conta inicial de uma base vazia: Roger / 12345678. Reiniciar a API preserva os dados que forem criados.

Código de configuração: 180504. Ele libera somente a troca da URL deste aparelho, antes do login. Não autentica uma conta nem concede moderação. Ao sair da tela, a liberação termina. O administrador continua com acesso em Perfil → Administração → Conexão do serviço.

Uma API de outra base já usando a porta 3000 pode gerar aviso de conflito. Nesta máquina, você pode continuar operando a API pela pasta original APS2026 e usar esta cópia para mostrar o código. Em uma máquina nova, o iniciador usa, por padrão, %LOCALAPPDATA%/HydroPulse/server.db. Não é preciso importar banco particular.

Todo o código fica em codigo: mobile contém o app, server a API e SQLite, data a cópia oficial e scripts os auxiliares. O projeto nativo Android foi mantido. Os caminhos de código do roteiro começam dentro dessa pasta.
